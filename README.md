# Code Academy | منصة عربية لتعليم تطوير الويب من الصفر

منصة عربية تفاعلية مقالية لتعليم تطوير الويب خطوة بخطوة، من أول وسم HTML حتى بناء تطبيقات كاملة باستخدام React و Node.js.

---

## 🎯 الرؤية والجمهور المستهدف
- **الرؤية**: أي شخص ليس لديه خبرة برمجية سابقة يستطيع دخول المنصة، اتباع مسار واضح، قراءة الدروس المبسطة، تطبيق الأكواد عملياً، ومتابعة تقدمه حتى يصبح **Frontend Developer**.
- **الجمهور المستهدف**: المبتدئون تماماً (Beginner-Friendly)، مع تجهيز المنصة للتوسع بمستويات متوسطة ومتقدمة.
- **أسلوب التعلم**: مقالي تطبيقي (Article-Based) مدعوم بمختبر كود تفاعلي (Interactive Sandbox) واختبارات فهم سريعة (Quizzes) بنهاية كل درس.

---

## 🗺️ الهيكلية التعليمية (Learning Hierarchy)
تم الفصل بين المستويات الأربعة لمنع التشتت:
1. **Learning Path (المسار التعليمي)**: رحلة تعليمية كاملة لتحقيق هدف وظيفي (مثل Frontend Development).
2. **Course (المادة / الكورس)**: تقنية محددة داخل الرحلة (مثل HTML, CSS, JavaScript).
3. **Module (الفصل)**: وحدة موضوعية داخل الكورس (مثل Flexbox أو النماذج).
4. **Lesson (الدرس / المقال)**: مقال تعليمي مركز يقرأ في دقائق مع تطبيق كود واختبار فهم.

---

## 🚀 مسارات التعلم المعتمدة

### 1. مسار تطوير واجهات المستخدم (Frontend Development Path) — المسار الأساسي (Primary)
1. **HTML Fundamentals**: بناء هيكل صفحات الويب (Elements · Attributes · Forms · Semantic HTML).
2. **CSS Fundamentals**: تنسيق وتصميم صفحات الويب (Selectors · Box Model · Flexbox · Grid · Responsive).
3. **JavaScript Fundamentals**: برمجة التفاعل والمنطق (Variables · Functions · Arrays · Objects · DOM · Async).
4. **Git & GitHub**: إدارة الأكواد والمشاريع وتتبع الإصدارات (Git · Branches · Commits · GitHub).
5. **TypeScript**: كتابة JavaScript قوية بنظام الأنواع الثابتة (Types · Interfaces · Generics).
6. **React Development**: بناء تطبيقات واجهات المستخدم الحديثة (Components · Props · Hooks · Routing · State Management).

### 2. مسار تطوير الواجهات الخلفية (Backend Development Path) — التوسع القادم
- Node.js · Express.js · REST API · MongoDB · Authentication · Full Stack Projects.

## 🛠️ التقنيات المعتمدة (Tech Stack)

| الجزء | التقنية |
|---|---|
| **Frontend** | React 19 + TypeScript + Vite |
| **Styling** | Tailwind CSS v4 (RTL First + Cairo Font) |
| **Routing** | React Router DOM v7 |
| **API State** | TanStack Query v5 |
| **HTTP Client** | Axios |
| **Forms & Validation** | React Hook Form + Zod |
| **Article Content** | Markdown + React Markdown + Rehype Highlight (Atom One Dark) |
| **Backend** | Node.js + Express 5 + TypeScript + tsx |
| **Database** | MongoDB + Mongoose (مع مخزن ذاكرة سريع تلقائي للمطورين) |
| **Authentication** | JWT + HttpOnly Cookies + Bearer Token |
| **Icons** | Lucide React |

## 💻 طريقة التشغيل محلياً (Quick Start)

### 1. تشغيل واجهة المستخدم (Client)
\`\`\`bash
cd client
npm run dev
\`\`\`
الواجهة متاحة على: [http://localhost:5173](http://localhost:5173)

### 2. تشغيل الخادم (Server)
\`\`\`bash
cd server
npm run dev
\`\`\`
الـ API متاح على: [http://localhost:5000](http://localhost:5000)

## 🌟 مميزات منصة Code Academy
- **واجهة عربية أصيلة (RTL-First)** بتصميم عصري داكن مريح للعين أثناء القراءة الطويلة.
- **محتوى عربي غني ومتقن** يشرح المفاهيم المعقدة بمصطلحات وتشبيهات ملموسة للمبتدئين.
- **مختبر كود تفاعلي (Code Playground)** لتجربة وتعديل أكواد HTML/CSS/JS مباشرة داخل المتصفح مع معاينة حية وزر كشف الحل النموذجي.
- **اختبار فهم بنهاية كل درس (Interactive Quiz)** يقدم تغذية راجعة فورية وتفسيراً علمياً للإجابة الصحيحة.
- **متابعة الإنجاز والأوسمة (Dashboard)** لحفظ تقدم الطالب في الدروس، حساب نسبة إكمال المسار، وأوسمة الإنجاز التشجيعية.
- **نظام مصادقة متكامل (Authentication)** يدعم التسجيل والدخول بالبريد وكلمة المرور وحفظ الجلسات بـ JWT الآمن.
